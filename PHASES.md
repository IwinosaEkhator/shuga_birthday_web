# Build phases

## Phase 1 — Foundation (started)

Mobile-first visual system, page skeleton, placeholder media slots, content checklist, and asset folders.

## Phase 2 — Content intake

Collect all unfiltered media and messages. Make a shortlist, identify the strongest opening/final images, and map files to sections.

## Phase 3 — Full story build

Complete all 14 sections, wire galleries and videos, refine motion, add the two personal message pages, and implement the comedic ending.

## Phase 4 — Interaction and polish

Choose how Shuga's favourites are saved, add answer persistence, improve transitions, compress media, add captions/alt text, and tune for common phones.

## Phase 5 — Final review and launch

Proofread names and messages, test every button/video, verify mobile performance, publish, and do a private link check before sending it to Shuga.
